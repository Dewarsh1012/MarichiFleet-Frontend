# MarichiFleet — MERN Stack Transport ERP

This project is an enterprise Transport ERP and live control tower built on the **MERN Stack**:
- **MongoDB**: MongoDB Atlas database (`backend/src/db/models/index.ts`)
- **Express**: REST API layer (`backend/src/app.ts`)
- **React**: Modern React SPA client with Vite and Tailwind CSS
- **Node.js**: Backend server runtime (`backend/src/server.ts`)
